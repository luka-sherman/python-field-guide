    Libraries

    Libraries allow us to apply Python to real tasks. These are a few popular ones, but there are many.

    Utilities

    • collections

      Specialized containers: counting items, grouping with defaults, named tuples, fast queues.

      Counter: + - & | counts[item] elements most_common subtract total update

      defaultdict: default_factory get

      namedtuple: _asdict _field_defaults _fields _make _replace defaults=

      deque: append appendleft clear copy count extend extendleft index insert maxlen= pop popleft remove reverse rotate

      OrderedDict: == move_to_end popitem

      ChainMap: maps new_child parents

      User* wrapper: UserDict UserList UserString

    • datetime

      Calculating and formatting dates and times.

      date: creating a specific date strftime

      timedelta: difference between two dates strptime

    • math

      Rounding, roots, constants, and logarithms.

      floor: ceil trunc

      sqrt: isqrt pow

      pi: inf nan

      log2: exp log10

      isclose

    • random

      Random numbers, random picks, shuffled order.

      randint

      choice: sample shuffle

    • re

      Regular expressions: searching, extracting, and replacing text by pattern.

      search: compile

      findall: groups named groups

      sub

      split

    • time

      Reading the system clock, pausing execution, and measuring elapsed time.

      time

      sleep

      perf_counter

      localtime: strftime

      DataFrame
