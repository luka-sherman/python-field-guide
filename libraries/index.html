    Libraries

    Libraries allow us to apply the Python fundamentals to real tasks. These are a few popular ones, but there are many.

    Built-in libraries

    • csv

      Reading and writing spreadsheets.

      install · import · csv.writer · csv.reader · DictReader

    • datetime

      Calculating and formatting dates and times.

      install · import · date · timedelta · strftime() · strptime()

    • json

      Reading and writing JSON data: nested dicts and lists, saved to a file or a string.

      install · import · json.dump() · json.load() · json.dumps() · json.loads()

    • random

      Random numbers, random picks, shuffled order.

      install · import · randint() · choice() · shuffle() · sample()

    • Tkinter

      Creating desktop applications: text, buttons, dropdowns, forms, output, etc.

      install · import · Tk() · Button · pack() · configure() · command · ttk.Style · messagebox · winfo_width() · putting it together

    Third-party libraries

    • matplotlib

      Charts and plots: line, bar, and scatter, built directly from plain Python data.

      install · import · line plots · bar charts · scatter plots · subplots · saving a figure

    • NumPy

      Fast numeric arrays, with math applied to a whole array at once instead of item by item.

      install · import · ndarray · array operations · arange() · mean() · boolean mask

    • OpenCV

      Real-time image and video analysis, built directly on NumPy arrays: color spaces, edge detection, face detection.

      install · import · reading, displaying, saving images · drawing · color spaces · CascadeClassifier · VideoCapture() · basic operations · thresholding, edge detection · blurring · contours · imread() · cvtColor() · Canny() · resize()

    • pandas

      Tabular data: rows and columns, like a spreadsheet, built on top of NumPy.

      install · import · DataFrame · working with a DataFrame · sort_values() · mean()

    • Pillow

      Opening, editing, and saving images, built around one Image object.

      install · import · why Pillow? · Image · ImageOps · ImageDraw · ImageFont · ImageColor · ImageFilter · ImageEnhance · ImageChops · convert() · ImageSequence · putting it together

    • requests

      Fetching data over the internet, like asking a website or API for information.

      install · import · get() · error handling · status_code · json() · params
